# 📋 财务报告复核工作流

> 一句话：把一份财务报告或审计报告丢给它，它会像请了一整个专家团队那样，从头到尾帮你查一遍，最后交给你一份"问题清单"和一份"改好的报告"。

---

## 🎯 这是什么

这是一个**报告复核技能包**，专门对付财务报告、审计报告、专项报告的全面检查。

你可以把它想象成一个"复核工作室"。它自己不带脑子——它是给人工智能助手用的说明书。人工智能助手读了它，就知道该按什么顺序干活、每一步查什么、查出问题怎么记、最后怎么交活。

**它有两大特点**：

- 📦 **自包含**：干活需要的全部资料都装在这个包里，不依赖外面任何其他工具或技能包。下载走、换台电脑、断网，都不影响使用。
- 🪶 **省脑子**：为内存小的模型专门做过瘦身优化。说明书自带"速查表"，平时只读薄薄几页就能干活；只有遇到疑难杂症才去翻后面的详细资料，而且翻哪页、什么情况翻，都写得清清楚楚。

### 🌟 它能查出什么

- 📊 **数字对不对**：报告里的数字和你给的权威资料（比如财务报表、台账）对不对得上，期初期末接不接得上
- 🧠 **逻辑通不通**：业务描述和数字是不是一回事，差异有没有追根因，而不是一句"差异较小"糊弄过去
- 📖 **准则合规吗**：关联交易、坏账计提、资产划转这些敏感事项，按会计准则和监管要求处理得对不对
- ⚠️ **资产有没有雷**：大额挂账、异常账龄、隐性负债这类资产质量风险有没有被揭示
- ✍️ **文字顺不顺**：错别字、病句、专业术语不规范，还有最烦人的"AI 腔"（空话、套话、模板句）——这些它都揪
- 📐 **排版规范吗**：报告文号、签章、表格格式这些形式要件齐不齐

## 🛠 使用方式

### 第一步：准备材料

把两样东西准备好：

1. **要检查的报告**：财务报告、审计报告或专项报告，Word、PDF 都行
2. **权威基准资料**：用来核对数字的"标准答案"，比如已审财务报表、台账明细、上期报告等

### 第二步：开口触发

在支持技能的智能助手（比如 WorkBuddy）里，用下面任意一句话就能启动：

- "复核报告"
- "审报告"
- "全面复核"

### 第三步：回答一个问题

启动后它会**一条消息**把所有事情交代清楚：检查范围、交付物、默认规则，外加唯一一个问题——"哪些资料作为权威基准？"

你指认一下哪个文件是"标准答案"就行。**回复即开工**，不会再有第二次确认打断你。

### 第四步：中途随时喊停

正式开查之后全程自动跑，不停不问。想调整范围或优先级，随时说一声"停"就行。

唯一可能主动停下的情况：查出的问题超过 30 条时，它会先给你最要命的 20 条，问你要不要继续看细节——这是怕刷屏，不是拖拉。

### 第五步：收活

最后你会拿到两样东西：**问题清单**和**修改版报告**。不满意可以让它继续深挖，满意就收工。

## 🔄 运行逻辑

整个流程是一条固定的流水线：先对齐需求，然后六步检查，最后汇总交付。

### 🪶 先说"省脑子"的设计（小模型友好）

干这类复核活有个天然难题：详细资料非常多（光专家思维框架和准则原文就近乎一本书），小内存的模型一口气读不完。这个包用三个办法解决：

1. **速查表优先**：每个检查步骤都配一张"速查表"，列着最关键的检查点。平时只读速查表就能干活，详细资料降级为"疑难才翻"。
2. **只读一次**：报告全文只在开头通读一遍，之后每步要用哪段查哪段，不反复翻全文。
3. **限量记录**：每步的中间结论限长，对照表只记差异行。宁可记录简略，也不跳过检查。

实测效果：改造后全程必读的内容从约 7.5 万字压到约 1.5 万字，**省掉约八成**。再大的报告也有余量。

### 六步都在查什么

**第 1 步 · 深度阅读** 📖
把报告从头读一遍（全文只读这一次），提取关键数字建"数据对照表"，标好各章节位置供后面查片段。同时判断这份报告是"正式稿"还是"草稿"——草稿没文号没签章是正常的，正式稿缺了就是问题。

**第 2 步 · 数字比对** 🔢
拿你指定的权威资料和报告逐个数字对。两条路线：一条查"期初衔接"（上期期末和本期期初对不对得上），一条查"同口径验证"（同一期间的数字对不对得上）。每个差异都留痕：在哪个文件、哪个位置、原值多少、差额多少。算术全部由包内自带的计算脚本用精确小数运算，不心算、不毛估。最后顺带查关键数字有没有标注来源。

**第 3 步 · 逻辑审查（田川视角）** 🧠
用一套资深审计经理的思维框架来查，速查表里有 8 个思维模型，覆盖：业务和财务对不对得上、底稿是不是从面到点层层展开、各部分报告是否均衡、有没有机械套模板、报表之间的勾稽关系。核心信条：发现差异必须追根因。

**第 4 步 · 准则审查（陈奕蔚视角）＋ 资产检查** 📖
用一位深耕会计准则二十余年的专家的思维框架来查，速查表里有 5 个思维模型，重点盯：法律形式和经济实质是否一致、关联交易价格是否公允、复杂交易用的准则对不对。同时做资产质量粗查：大额异常资产、隐性负债、对单一客户或关联方的依赖、风险揭示够不够。**请注意**：资产检查里原本还有一个私募尽调视角，因版权不允许公开分发，本包没有收录（只做降级人工粗查，记录里会如实标注，不冒充尽调深度）。

**第 5 步 · 文字质量审查** ✍️
一张文字审查速查表管到底：错别字、病句、专业术语规范、去 AI 味（删空话、合并重复、打散模板句）、活人感（把机构腔、口号腔改写成一个见过事、查过材料的人在说话）。

**第 6 步 · 汇总排版** 📐
把前面所有发现汇总成问题清单，再按事务所排版标准查文号、签章、表格格式、日期关系，最后输出成品。

### 🛡 出错怎么办

每种意外情况都预先写好了应对办法，格式是"什么情况 → 先怎么救 → 救不了怎么办"：

- 包里文件缺了：先看是不是被移动改名，能恢复就恢复；恢复不了就明确报错停止，绝不硬着头皮编
- 数字对不上：完整记录差异继续查，不按比例"忽略小差异"
- 缺基准资料：标注"无法比对"，不猜数字
- 问题太多（超过 30 条）：先给你最要命的 20 条，问你要不要继续看细节
- 模型内存吃紧：先砍过程记录、再合并结论，但检查步骤一个不少

## 📥 输入要求

启动时需要你提供这些东西：

| 材料 | 必要性 | 说明 |
|---|---|---|
| 📄 待复核报告 | **必须** | 财务报告、审计报告或专项报告，Word、PDF 格式均可 |
| 📚 权威基准资料 | **必须** | 用来核对数字的依据，比如已审财务报表、台账明细、上期报告。哪份算数由你指定 |
| 📝 报告状态说明 | 建议告知 | 这份是正式稿还是草稿？草稿可以不纠结文号和签章 |
| 🎯 复核重点（可选） | 可选 | 如果只关心某几个方面，比如"重点查关联方披露"，可以说明 |

**小提示**：资料给得越全，查得越细。如果只给报告不给基准资料，第二步的数字比对就只能标注"缺少基准来源"了。

## 📤 输出内容

全部查完后交付两样核心成果。输出排版有一个铁规矩：**站在人的角度，让人一眼看到要找的东西，不把筛选和归纳的活儿甩给用户**。所有交付物按三层结构组织：

### 第一层 · 问题概览 🎯

最先看到的一张小卡片：致命几条、重要几条、细节几条，最要命的问题各占一句话列出来。看完这屏就知道报告能不能出、雷在哪。

### 第二层 · 问题明细 📋（给人看的主表）

按"致命→重要→细节"排序，同级内按业务模块归并。每条问题只有五行，全是人话：

| 行 | 你会看到什么 |
|---|---|
| **问题** | 严重程度 + 一句话结论，比如"营业收入披露与利润表对不上" |
| **错在哪** | 人话定位，比如"财务报表附注 · 收入披露 · 第 3 行" |
| **原文** | 报告里的原话或原数字，方便你直接比对 |
| **凭什么说错** | 判断依据：和哪份基准资料核对的、差多少、违反哪条要求 |
| **怎么改** | 具体修改建议，可以直接照做 |

### 第三层 · 技术留痕附表 🤖（机器信息全在这）

内部编号、数据文件路径、行号区间、工具日志这些机器字段，全部收进单独附表——人看的清单里一个都不出现，需要追溯时才翻。

问题超过 30 条时，先出前 20 条致命和重要问题，问你要不要继续展开细节，不会一股脑砸给你。

### 📝 修改版报告

按问题清单修订后的报告成品，干干净净只有改好的内容，不留任何机器标记。

**通用排版原则**（管住所有交付物）：结论先行、重点和异常排前面；按业务逻辑归并，先整体后明细、先重要后次要；只留有用信息；表格用日常列名、重要字段靠前；结果和依据分层；交付前自查"人能不能一目了然"。

### 2026-10-31 · 小上下文优化版

🧠 **为内存小的模型大瘦身**：

- **新增速查表体系**：田川视角 8 个思维模型、陈奕蔚视角 5 个思维模型全部收编成速查表（比旧版还多 3 个模型，覆盖更全）；新增一页文字审查速查。平时只读速查表干活，详细资料降级为"疑难才翻"。全程必读内容从约 7.5 万字降到约 1.5 万字。
- **新增小上下文纪律**：报告全文只读一次、深查资料禁止一口气全读、每步记录限量、内存吃紧时宁砍记录不砍检查。
- **流程七步并六步**：原第五步资产检查并入准则审查一步，少一次周转。
- **交互减负**：原来全程要停 4 次等确认，现在只在开场停 1 次（一条消息交代全部事项，回复即开工）。原"查完数字问一句""排版前再问一句"等重复确认全部取消，中途随时可喊停。
- **消除重复劳动**：删掉一个"只负责传话"的过渡文件（此前会导致同一份规则被读两遍）；排版检查不再读脚本代码；全面禁止同一份报告反复重读。

## ⚠️ 注意事项

1. **资产质量检查是降级版**：私募尽调视角因版权限制未收录（详见包内决策记录），该部分只做人工粗查，别拿它当完整尽调使。
2. **不替代专业判断**：它帮你找问题、给建议，但改不改、怎么改，最终由你（或你的注册会计师）拍板。
3. **数字核对依赖基准资料**：基准资料给错了，核对结论也跟着错——"标准答案"的选择权在你手里。
4. **测试产物会自动忽略**：包内自带的自动化测试运行时会生成临时文件，已配置为自动忽略，不会污染仓库。
